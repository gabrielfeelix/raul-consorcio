# Raul Consórcio

Projetos para o Raul Carvalho — Raul Consórcios Multimarcas, especialista em consórcios multiempresas.

**Ordem atual:** plataforma e calculadora primeiro; LP depois, com mais referências.

| Pasta | Projeto | Status |
|---|---|---|
| [`website/`](website/) | **Landing page** para o Raul se vender (+ blog) | v2 no ar em https://raul-consorcio.vercel.app · v3 depois, com mais referências |
| [`calculadora/`](calculadora/) | **Calculadora de consórcio** (imóvel): compara consórcio × financiamento × CDB × Tesouro Selic, com linha do tempo arrastável e PDF | protótipo em `calculadora/app` (localhost:5174) |
| [`plataforma/`](plataforma/) | **Plataforma de indicações e prêmios**: parceiros cadastram e acompanham indicações, com níveis Bronze→Platinum, comissão e dashboard do Raul | protótipo em `plataforma/app` (localhost:3100), dados de exemplo, sem banco |

Cada pasta é um projeto independente, com seu próprio README e deploy.
